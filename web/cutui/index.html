To draw a cut, click the plot to add vertices, then select “Close polygon” (at least three points). Drag the yellow handles to adjust vertices. Select “New cut” to start over.

Save Cut writes the editor polygon to the selected macro/*.root file (overwriting that file if it exists). Load Cut retrieves the selected saved polygon. Apply Saved loads and activates the selected file; Apply Edited activates the current polygon without saving. Neither apply operation reprocesses earlier events. Default file: macro/pid_f2.root.
