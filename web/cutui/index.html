To draw a cut, click the plot to add vertices, then select “Close polygon” (at least three points). Drag the yellow handles to adjust vertices. Select “New cut” to start over.

Save Cut writes macro/pid_f2.root with a ROOT TCutG named pidcut_f2. Load Cut retrieves the saved polygon for editing. Neither operation changes the cut currently used by the running analysis; restart enana to use the saved cut. The first vertex is not duplicated in the JSON list.
